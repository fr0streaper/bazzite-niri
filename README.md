# bazzite-niri

A custom image based on Bazzite-DX with the intention to keep as close to Bazzite as possible but with [niri](https://github.com/YaLTeR/niri) as the window manager and Noctalia shell for enabling the expected desktop environment experience.

## Switching to bazzite-niri

```
sudo bootc switch ghcr.io/fr0streaper/bazzite-niri
```
